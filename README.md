A program that draws the passport spread of the invented Republic of Meridia — data page with portrait and machine-readable zone, ferry visa, arrival card and nine matching border stamps — and writes it to /output/entry.png.

## Run it

```sh
python3 main.py entry.png
```

Pure Python 3 standard library: the picture is drawn pixel by pixel (no fonts, no image libraries, no network), so it runs in the sandbox exactly as it runs here. Every date is consistent: the passport was issued 02 JUN 2023 and every stamp falls after that date, in ascending order, each arrival matched by a later departure.
